# Student Marks Analyzer 📝

## 📌 Project Description
Student Marks Analyzer is a simple Python-based project that helps analyze a student's academic performance. It accepts marks for multiple subjects and calculates the total marks, average, and percentage. It also assigns grades based on clearly defined conditions and displays the highest and lowest subject marks.

## 🎯 Features
- Accepts student name and number of subjects.
- Takes subject names and marks as input.
- Calculates total marks.
- Calculates average marks.
- Calculates percentage.
- Assigns grades using if-elif-else conditions.
- Displays the highest and lowest marks with subject names.
- Checks for invalid marks (below 0 or above 100).

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Concepts:** Variables, Lists, Loops, Conditional Statements, Built-in Functions.

## ⚙️ How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or IDLE.
4. Run the Python file:

```bash
python student_marks_analyzer.py
```

5. Enter the student name, number of subjects, subject names, and marks.
6. View the final result.

## 📊 Grading System

| Percentage | Grade |
|---|---|
| 90–100% | A+ |
| 80–89.99% | A |
| 70–79.99% | B |
| 60–69.99% | C |
| 50–59.99% | D |
| 40–49.99% | E |
| Below 40% | F |

## 🧮 Calculations

- **Total Marks:** Sum of marks obtained in all subjects.
- **Average:** Total Marks / Number of Subjects.
- **Percentage:** (Obtained Marks / Maximum Marks) × 100.
